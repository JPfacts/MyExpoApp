# MyExpoApp
error commands 
Problem | Command |
| --- | --- |
| Cache Error | `npx expo start --clear` |
| Package Issues | `npm install` |
| Dependency Check | `npx expo doctor` |
| Expo Server Stop | `Ctrl + C` |
| Network Problem | `npx expo start --tunnel` |
### A. Project Commands

| Command | ఉపయోగం |
| --- | --- |
| `code .` | VS Codeలో Project Open |
| `cd MyExpoApp` | Project Folderలోకి వెళ్లడం |
| `dir` | Files చూడటం (Windows) |
| `cls` | Terminal Clear (Windows) |
| `npm install` | Packages Install |
| `npm start` | Project Start Script |
| `npm run` | Available Scripts చూడటం |

### B. Expo Commands

| Command | ఉపయోగం |
| --- | --- |
| `npx expo start` | Expo Server Start |
| `npx expo start --go` | Expo Goలో Run |
| `npx expo start --tunnel` | Tunnel ద్వారా Connect |
| `npx expo start --clear` | Cache Clear చేసి Start |
| `npx expo install` | Expo-compatible Packages |
| `npx expo doctor` | Project సమస్యలు Check |
| `npx expo --help` | Expo Commands Help |

### C. Terminal Keyboard Shortcuts

`npx expo start` నడుస్తున్నప్పుడు:

| Shortcut | పని |
| --- | --- |
| `a` | Android Emulator Open |
| `i` | iOS Simulator Open |
| `w` | Web Browser Open |
| `r` | App Reload |
| `m` | Developer Menu |
| `j` | React Native DevTools |
| `o` | Project Editorలో Open |
| `s` | Expo Go / Development Build Switch |
| `?` | అన్ని Shortcuts చూడటం |
| `Ctrl + C` | Server Stop |
